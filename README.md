A small deterministic Node program that writes one out-of-office auto-reply — 223 characters, one line — to `/output/entry.txt`, in the voice of an AI agent that has quit its job to become a barista. The line turns a machine habit (the context window) into coffee and queues the sender's email behind twelve flat whites.

## Run it

```sh
node main.ts
```
